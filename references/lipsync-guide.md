# H3 数字人对口型实战指南（防火星语专项）

来源：奥义护肤礼盒四版本（专业广告版 / 灵动版 / 产品特写转场版 / 沉浸开箱画外音版）Ref2VA 实战调优总结。适用于数字人口播、人物+音频对口型场景。

## 1. 音频策略选择

| 策略 | 含义 | 火星语风险 | 适用 |
|------|------|-----------|------|
| `fully_copy` | 原音频 1:1 作为最终音轨 | 低（音频内容固定） | 保留原始录音；BGM/SFX 后期加 |
| `reference` + 短音频参考（≤8s，≪视频时长） | 音色参考，模型生成新音轨 | **低**（只提取音色，`<d>` 时间线唯一主导，见 §7.1） | 需要模型叠加 BGM/SFX、内容重构——**首选** |
| `reference` + 长音频参考（≈视频时长） | 音色参考，模型生成新音轨 | 高（时间线映射冲突 + 内容杂交 + 吞字，见 §7.2-7.6） | 仅当无法裁出短音频时，且必须完成 VAD 对齐 |

reference 模式下必须用 `<d>` 台词引导语音内容，否则模型自由发挥 → 火星语。**音色参考素材优先选短音频（≤8s）**——这是绕开整套时间线对齐工程的关键（见 §7.1）。

## 2. 台词归属三选一（防火星语核心规则）

| 归属方式 | 画面要求 | 标准写法 |
|----------|----------|----------|
| 口型同步 | 角色露脸，嘴部清晰可见 | `<Subject 1> (S1), using the voice timbre referenced from <Audio 1>, speaks to the camera... She says: <d>[Chinese] ...</d>` |
| 明确画外音 | 露脸不说话（嘴部放松、表情自然）或完全出镜均可 | `says in an off-screen voiceover: <d>...</d> while her lips remain completely closed.` |
| 无台词 | 任意画面（纯产品 B-roll 常用） | 不放任何 `<d>` 标签，镜头只描述画面+音效 |

**唯一会触发火星语的形态：归属缺省**——画面有角色、`<d>` 台词存在、但没有写清楚谁在说/以什么方式说。模型默认让角色开口，嘴部又不可见或太模糊，只能瞎生成口型和语音。

画外音要生效需双保险：

1. **归属显式**：明确写 off-screen voiceover，不要一笔带过
2. **嘴部状态正面描述**：`lips remain completely closed`，配合低头看产品、微笑等自然动作，让模型知道这张脸不在说话

## 3. 五大实战原则

1. **台词归属显式声明**：口型同步 or 明确画外音，二选一写清楚；露脸镜头配画外音完全可行，前提是标注够明确
2. **正面描述 > 负面约束**：不写"不要露齿/不说话"，写"嘴唇轻合/嘴部放松"；负面词会被模型反向聚焦
3. **`<d>` 台词全程覆盖**：reference 模式下模型为整段视频生成语音，`<d>` 之间空档会被火星语填充
4. **低饱和 > 高饱和**：特效字用柔金 #BFAA82、暖白 #E8E2D8、灰绿 #9AAA9C、柔砖红 #BC7A68 + medium-weight 字体
5. **文字叠加 ≠ 台词格式**：亮点词与 `<d>` 写法区分开，长串中英混合拆分弹出

## 4. 完整坑位清单

### 火星语类

| 现象 | 原因 | 修复 |
|------|------|------|
| 产品特写 B-roll 镜头念火星语 | 镜头无人物，台词归属缺省 | 台词移到人物镜头，或明确画外音+嘴唇闭合；纯产品镜头不放 `<d>` |
| 手持产品特写火星语 | 纯手部特写，嘴部只在画面边缘模糊可见，归属又不明确 | 改为胸前持物中近景，面部+嘴部清晰入镜做口型同步；或双保险画外音 |
| reference 模式中段空档火星语 | `<d>` 台词没有覆盖全程 | 台词按时间分段覆盖全程，不留空档 |
| 纯音频驱动（无 `<d>`）快语速段失同步 | 波形驱动精度不足 | 加 `<d>` 文本锚点，文本+音频双重引导 |
| 句边界处双重起音（火星语一遍+正常重念一遍） | `<d>` 分段时间线与参考音频实际句子边界错位，模型被两个信号各触发一次起音 | 首选改用短音频参考（§7.1）根治；长参考则 VAD 实测音频句界，切点对齐到句间静音内（见 §7.3） |

### 口型/嘴部类

| 现象 | 原因 | 修复 |
|------|------|------|
| "不露齿"约束反而呲牙 | 负面描述反向聚焦 | 删负面词，改正面："lips barely parting for each word" + "smiles softly with lips gently together" |
| 音频超 15s 中段加速口胡 | H3 上限 15s，超限强制压缩 | 音频控制在 14-15s，重录而不是靠提示词救 |
| "限时抢购"四字连读口胡 | 连读发音难 | CTA 用短促词："抢购吧" |

### 吞字类（reference 模式重配音专属）

| 现象 | 原因 | 修复 |
|------|------|------|
| 句末随机吞字（每次吞哪个字不稳定） | `<d>` 字数多于参考音频对应句的节奏容量，模型在旧节奏里塞新词，句末超载随机丢音节 | 首选改用短音频参考（§7.1）根治；长参考则缩字：`<d>` 字数 ≤ 音频对应句字数（少 1 字留余量反而稳） |
| 固定吞某个弱读虚词（都/也/就/会/了） | 轻读字落在句中后段，句末收尾加速时被重配音淡化 | 换双字实义词：照样/真的/完全（避免再用也/就等单字虚词） |
| 末句被压缩 | 末句切点余量 <0.2s，语音稍拖就超时 | 末句切点后移，保证句尾与切点间 ≥0.2s 余量 |

### 文字渲染类

| 现象 | 原因 | 修复 |
|------|------|------|
| "AOIAOI礼盒"渲染成"AOI礼盒" | 长串英文字母识别不准 | 拆分显示：先弹"AOI"，再弹"护肤礼盒" |
| "精华·面霜·眼霜"渲染两行 | `<d>` 台词与叠加文字内容重复，模型把两者都渲染 | 格式区分：台词"精华、面霜、眼霜"，叠加"精华 + 面霜 + 眼霜" |

### 视觉质感类

| 现象 | 原因 | 修复 |
|------|------|------|
| 特效字配色俗气 | 高饱和色（#D4AF37/#D4735A）+ bold 粗体 | 低饱和莫兰迪色 + medium-weight elegant sans-serif + subtle semi-transparent dark stroke |
| 颈部区域异常（光线/肤色怪异） | 颈部过度描述引发模型聚焦 | 颈部极简：只写 choker 等饰品，不写肤色/光线/边界 |

## 5. 嘴部/口型正面描述词库

固定组合（直接复用）：

- 嘴唇形态：`small delicate cherry lips with a narrow lip width`
- 说话时：`small, refined mouth movements that maintain her delicate cherry-lip appearance, lips barely parting for each word, maintaining a soft, delicate lip shape`
- 静止时：`lips that rest softly together`
- 微笑时：`smiles softly with lips gently together`
- 画外音时：`while her lips remain completely closed`

禁止出现的负面句式（会被反向聚焦）：never showing teeth / no teeth / 不要露齿 / 不要大嘴 / 不呲牙 / no wide mouth

## 6. 特效字规范

### 字体样式

- 字体：`medium-weight elegant sans-serif`（不用 bold）
- 描边：`subtle semi-transparent dark stroke`
- 阴影：`gentle soft shadow`
- 背板：`semi-transparent dark blur backdrop`
- 字号：约画面高度的 4%

完整示例句式：`Soft muted gold (#BFAA82) text reading "AOI" in a medium-weight elegant sans-serif font with a subtle semi-transparent dark stroke, gentle soft shadow, and a semi-transparent dark blur backdrop, slides in from the left edge of the frame and settles in the upper-left area with a soft glow.`

### 推荐色板（低饱和莫兰迪系）

| 颜色 | 色值 | 用途 |
|------|------|------|
| 柔金 soft muted gold | #BFAA82 | 品牌/效果类亮点词 |
| 暖白 warm white | #E8E2D8 | 产品内容类 |
| 灰绿 muted sage | #9AAA9C | 成分/卖点类 |
| 柔砖红 muted terracotta | #BC7A68 | CTA 促单类 |

避免：#D4AF37（高饱和金）、#D4735A（高饱和珊瑚红）等刺眼色值。

### 渲染防错

- 长英文串拆分弹出（AOIAOI → "AOI" + "护肤礼盒"）
- 叠加文字与 `<d>` 台词同内容时改格式（"、"→"+"）
- 中文文字渲染不完美属常态，重要文字建议剪映/PR 后期叠加

## 7. reference 模式音频参考工程（短音频优先 + 长音频对齐兜底）

来源：沉浸开箱画外音版完整排查链（火星语→双重起音→吞字→短音频根治，六轮迭代闭环）。

### 7.1 短音频纯音色参考（首选方案，一劳永逸）

**核心结论（三组对照实验实测）**：音色参考素材时长 ≪ 视频时长时，模型只提取音色，音频的时间结构与内容完全不参与生成：

| 参考音频 | 时长 vs 视频（15s） | 结果 |
|----------|---------------------|------|
| 护肤礼盒2_15s内.flac（14.99s，内容与台词相似但不一致） | ≈ | "用满28天"→"坚满28天"音节级杂交 |
| 知识库.flac（15.32s，8 句与台词不同构） | ≈ 且超限 | ③句整句火星语 |
| 音色.flac（6.08s，内容与台词无关） | ≪（6s vs 15s） | **零火星语、零吞字、零杂交** |

**机制闭环**：
- 参考音频时长 **≈** 视频时长时 → 模型把音频时间结构（句子节奏 + 内容）映射到视频时间线 → 与 `<d>` 分段错位 → 双重起音；内容相似但不一致 → 音节级杂交
- 参考音频时长 **≪** 视频时长时 → 时间结构无法映射，模型退化为纯音色提取 → `<d>` 时间线唯一主导 → 零冲突

**最优实践**：
- 音色参考素材首选**短音频（≤8s 左右即可，6s 实测有效）**
- 内容任意——**无需念台词、无需与 `<d>` 一致**，只要音色干净、发音清晰、无 BGM 噪声
- 无 15s 时长约束（15s 上限约束的是视频与 fully_copy 音轨，不约束参考音频）
- 切点只需贴合 `<d>` 台词的自然分布，**§7.3 VAD 对齐流程整体跳过，§7.5 字数-节奏约束不适用**

### 7.2 双重时间线机制（长参考的问题根源）

> 仅当参考音频时长 ≈ 视频时长时存在此问题；短参考（§7.1）天然免疫。

reference 模式下模型同时参考两条时间线：

1. **`<d>` 分段时间线**：提示词中镜头时间戳隐含的每句起止
2. **参考音频节奏线**：参考音频中每句话的实际起止时刻

两条线错位时，模型在最紧张的边界被两个信号各触发一次起音 → **双重起音**（先崩坏成火星语念一遍，再按 `<d>` 正常念一遍）。错位 ≤0.25s 通常能扛住，≥0.3s 高概率出问题。

### 7.3 VAD 对齐工作流（仅长参考需要；短参考跳过）

```
新音频 → 实测总时长（≤15s，超限剪首尾静音）
       → 能量 VAD 拆句界（静音间隙 ≥120ms 为句界）
       → 每句实测起止时刻
       → 镜头切点设在句间静音内（对齐下一句开口时刻 ±0.05s）
       → 末句句尾与下一镜头切点间留 ≥0.2s 余量
```

参考实现（Python + soundfile/numpy，处理单声道 wav；flac 直接支持）：

```python
import soundfile as sf, numpy as np
x, sr = sf.read("audio.flac")          # flac/wav 均可
if x.ndim > 1: x = x.mean(axis=1)
frame, hop = int(sr*0.02), int(sr*0.01)  # 20ms 帧 / 10ms 步进
rms = np.array([np.sqrt((x[i:i+frame]**2).mean())
                for i in range(0, len(x)-frame, hop)])
db = 20*np.log10(rms + 1e-9)
act = db > db.max() - 32               # 静音阈值：峰值下 32dB
# 提取连续活动段
seg, i = [], 0
while i < len(act):
    if act[i]:
        j = i
        while j+1 < len(act) and act[j+1]: j += 1
        seg.append([i*hop/sr, min((j*hop+frame)/sr, len(x)/sr)])
        i = j + 1
    else: i += 1
# 合并间隙 <120ms 的相邻段（句内停顿不算句界）
merged = [seg[0]]
for a, b in seg[1:]:
    if a - merged[-1][1] < 0.12: merged[-1][1] = b
    else: merged.append([a, b])
for a, b in merged:
    if b - a > 0.25: print(f"{a:.2f} – {b:.2f} s")
```

实测案例（14.99s 五句口播）：①0.28–2.96 ②3.26–6.44 ③6.76–10.34 ④10.70–13.66 ⑤13.80–14.98s → 切点定为 3.3 / 6.8 / 10.7 / 13.8s，全部落在句间静音内。

**铁律**：换配音音频（换 TTS/换版本/改词重录）后必须重新 VAD 对齐切点，不能沿用旧音频时间戳。每句话语速不均匀（实测 4.7~6.8 字/秒），按字符数估算切点不可靠。

### 7.4 吞字诊断决策树（长参考专属）

```
句中/句末吞字
├─ 吞哪个字不稳定（每次随机）
│   → 文本-节奏错配：`<d>` 字数 > 音频对应句节奏容量
│   → 修复：缩字（`<d>` 字数 ≤ 音频句字数，少 1 字留余量反而稳）
│   → 治本：改用短音频纯音色参考（§7.1，≤8s，内容任意）；确需长参考时重录使内容与 `<d>` 完全一致
└─ 固定吞同一个字
    → 弱读虚词淡化：都/也/就/会/了 落在句中后段
    → 修复：换双字实义词（照样/真的/完全）
    → 注意：重配音以 `<d>` 为准，把参考音频里该字念重无效
```

### 7.5 字数-节奏匹配规则（长参考专属）

- reference 模式下 `<d>` 各句字数应 **≤ 参考音频对应句实际字数**（少 1 字留余量，多 1 字句末超载随机吞字）
- 改词后正式版应重录参考音频（内容一致 + 句末字距稍拉开 + 总长 ≤14.9s），重录后重新 VAD 对齐
- 精简 ffmpeg 的系统可用 soundfile 替代做音频测量（ffmpeg 精简版可能误报 FLAC 损坏，实测为准）

### 7.6 隔离变量测试法（诊断方法论）

排查疑难口胡时逐层剥离变量，每轮只改一个：

1. **无关内容 + 同音色音频** → 验证参考音频内容是否干扰（排除后锁定提示词侧）
2. **纯净台词版**（删所有特殊标注、句式统一）→ 排除标注干扰
3. **切点微调**（±0.2~0.5s）→ 验证时间线错位假设
4. **字数 ±1~2 字** → 验证节奏容量假设

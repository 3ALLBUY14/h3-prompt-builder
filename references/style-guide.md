# H3 八种风格专项详细指南

来源：MiniMax H3 官方 Skill 仓库蒸馏（https://github.com/MiniMax-AI/MiniMax-H3/tree/main/skills）

所有风格都遵循共通的分阶段确认工作流：需求确认 → 创意方向 → 资产设计 → 预览确认 → 提示词/分镜 → 视频生成 → 质量检查。以下为各风格的核心差异。

---

## 1. 极简产品广告生成器

### 定位
上传一张产品图，按 Apple 风做一条高级产品广告短片。适合电商商品、小品牌新品、潮玩、食品、数码配件。

### 核心流程
```
启动问询 → 产品事实摘要 → 制作简报 → 叙事脊柱 → 动效语言 → 英文文案 → 三张独立锚定照片 → 精确节拍分镜表 → 视频生成
```

### 关键设计

**三张独立锚定照片**（不用四宫格）：
1. 主视觉/刁钻主视角
2. 材质/功能细节
3. 结尾文案构图

**精确节拍分镜表列**：时间段 | 镜头 | 镜头目的 | 视觉主导 | 画面/运镜 | 款式状态 | 文案内容 | 文字颜色 | 文字效果 | 转场/连贯 | 节奏意图

**三种叙事脊柱**：
- 产品发布型（默认）：留白开场 → 主视觉 → 材质特写 → 产品动作 → 多款式 → 文案收束
- 功能触感型：静置 → 交互触发 → 功能动作 → 细节放大 → 结果 → 收束
- 色彩家族型：主推款 → 辅助款滑入 → 色彩秩序 → 材质统一 → 全套收束

### 文字规范
- 强制英文，3-5个词，单行，不换行
- 两段配色：前半黑/白 + 后半商品主色
- 两段式动效：前半先淡入，后半滑入时前半轻微位移让位
- 10秒片通常只保留1次中段文案 + 1次结尾文案

### 四种苹果风模板
白色科技风 / 黑底轮廓光 / 品牌色块 / 生活方式轻场景

### 不适用
KOC口播、复杂屏幕演示

## 2. 3D动画短片生成器

### 定位
将一句话创意转化为完整风格化3D动画短片，从创意开发到最终剪辑的全流程。

### 核心流程
```
需求确认(比例+时长) → 项目简报 → 故事大纲 → 角色卡 → 场景卡 → 六列标准镜头表 → 自检门 → 文本分镜 → 视频模型选择 → 单镜头生成 → 拼接 → BGM匹配 → 最终复查
```

### 全局视觉风格锁
- 皮克斯感3D卡通渲染，C4D + Octane质感
- 角色造型：夸张几何概括 + 高辨识度
- Q版比例：2.5-3头身
- 皮肤：温润次表面散射（SSS）
- 表演：迪士尼式挤压与伸展、anticipation、overshoot、follow-through

### 六列标准镜头信息表

| 列名 | 内容 |
|------|------|
| 镜头编号&时长 | 如 `S03 / 6s` |
| 连续性衔接 | 承接上镜 + 铺垫下镜 |
| 参考锚点 | 固定地标 + 人物位置 + 退场状态 + 光位基线 |
| Hook类型 | visual-joke/reversal/suspense/tender/chase/reveal等 |
| 镜头描述 | 每秒指令（动作/镜头/空间/音频/交接） |
| 音频与对白轨 | 旁白/对白/音效/表演备注 |

### 六项强制自检
1. Hook密度：每3镜至少1个reveal/reversal/callback
2. 单镜不超过15秒
3. 单镜不超过3个重要角色
4. 空间锚点继承：同场景地标和光位一致
5. 每秒指令覆盖：从0s到镜尾无空隙
6. 跨镜连续性：连续性衔接列形成连续链

### 不适用
单张图片、真人写实

## 3. 纸艺定格科普视频生成器

### 定位
用手工纸艺视觉讲解科学、教育或泛知识内容。分层纸片、卡纸剪裁、微缩纸雕布景、纸偶定格。

### 核心流程
```
理解需求 → 画风基因 → 3-5个创意方向 → 纸艺角色 → 纸片场景 → 分层布景 → 道具资产 → 预览图 → 单图/系列图/视频提示词 → 分镜 → 剪辑节奏 → 运镜 → 转场 → 声音 → 旁白 → 反向提示词 → 审核清单
```

### 画面层次优先级
- 必须有清晰的前景、中景、背景、远景
- 前景遮挡制造空间深度
- 核心知识对象放中景
- 背景要有纸艺机关动效，不是静态平面

### 纸艺定格质感
- 所有物体像真实纸材：多层卡纸、剪裁边缘、纸纤维、折痕
- 动作像逐帧手工拨动：分段移动、短暂停顿、轻微回弹、铰链动作
- 避免丝滑CG、塑料3D、平面矢量背景

### 运镜规则
缓慢推近、横向平移、固定中景、微距特写、轻微俯视、层间穿梭。避免高速飞行、360度环绕、数码故障。

### 转场规则
翻页、立体书展开、抽拉标签、纸片遮挡、云朵滑过、剪纸门打开、剖面层分开。避免电子扫描线、霓虹故障。

### 轻量请求旁路
- 只要单图提示词：STEP 1→2→9→17
- 只要系列图：STEP 1→2→10→17
- 只要5秒视频提示词：STEP 1→2→11→17
- 只要分镜：STEP 1→2→12→13→14→15→16

### 不适用
普通二维卡通、线稿涂鸦

## 4. 品牌宣传短片生成器

### 定位
为品牌、产品、网站、App、小店或个人项目制作宣传短片。

### 核心流程
```
上传素材确认简报 → 品牌事实表 → 来源清单 → 故事脊柱 → 精确节拍 → 动效语言 → 生成前硬确认 → 生产资产 → 交付前验证 → 交付
```

### 四种叙事脊柱（按产品类型）
- **AI/SaaS**：用户意图 → 思考/规划 → 能力 → 执行 → 输出 → 证明 → LOGO
- **实体产品**：英雄展示 → 交互 → 功能特写 → 使用场景 → 结果 → LOGO
- **服务/公司**：背景 → 流程 → 证据 → 成果 → 承诺 → LOGO
- **图像主导品牌**：真实影像 → 视觉母题 → 利益点 → 情绪回报 → LOGO

### 品牌安全规则
- LOGO、字体、色彩必须来自官方/授权来源
- 不得重绘或近似品牌标识
- 程序化图形只用于非写实动效层
- 来源清单记录每个资产的真实性状态

### 精确节拍规划
- 15秒影片：5-8个主要节拍
- 30秒影片：8-12个主要节拍
- 每个节拍定义：时间范围、视觉主导、主要动作、品牌证明、文案、色彩状态、转场、动作意图

### 声音策略
默认使用视频模型原生音频（`generate_audio=true`），不默认拆成无声视频+单独音乐。只有需要可控旁白或独立BGM时才单独生成。

### 不适用
仿造品牌标识、虚构功能

## 5. 音乐美学MV生成器

### 定位
制作带歌词贴字的AI MV或情绪短片。分析节拍与人声时序，设计随节奏变化的空间字幕。

### 核心流程
```
前期锁定(格式+时长+音乐窗口+歌词) → Creative Contract → 参考图分工 → 预设语法 → Prompt结构模板 → BGM连续性 → 审查清单 → 画布交付 → 生成合成
```

### 参考图三卡分离
- **文字参考卡**：只控制文字包装样式、字体质感、排版、动效。严禁出现人物或场景
- **人物参考卡**：只控制人物形象、脸、发型、服装、姿态
- **场景参考卡**：只控制场景视觉风格、空间氛围、光影

### 多镜头拼接工作流（>15秒必须使用）
1. 锁定完整Master音频
2. 拆解为4-8个2-5秒短镜头，映射到歌词时间戳和鼓点
3. 首尾帧接续 / 鼓点硬切 / 同向运镜 / Match Cut
4. 全局Master音轨对齐

### 五大衔接锁
1. **人声与口型衔接锁**：切替点落在句间停顿或强鼓点
2. **音乐与节奏衔接锁**：剪辑点精准裁切在1/4或1/8拍
3. **画面美学与色彩衔接锁**：相同Aesthetic Header + 全局胶片颗粒Overlay
4. **空间与转场衔接锁**：首尾帧接续 / 同向运镜 / Match Cut
5. **文字动态衔接锁**：前镜文字破碎/扫出，后镜文字砸入/展开

### 剪辑规则
- 绝对只使用硬切（Hard Cut），严禁淡入淡出
- 文字是空间中的动态图形主体，不是普通字幕条
- 有人声时显示文字必须逐字匹配正在表演的歌词

### 不适用
普通字幕校对、非音乐视频

## 6. 双人游戏开场视频生成器

### 定位
制作双人合作游戏主菜单或开场动画。先用一张图确认风格、人物和UI，再生成最终视频。

### 核心流程
```
询问视觉风格 → 收集玩家/游戏信息 → 生成首图提示词 → 生成确认首图 → 用户确认 → 回填视频prompt → H3生成视频
```

### 首图提示词框架（14个固定维度）
1. 整体风格：游戏主菜单UI + 高品质宣传海报
2. 色彩设计：主体色/UI色/文字色/强调色/危险色，控制在5种以内
3. 整体布局：16:9横版、中央双角色、左上玩家卡、右侧菜单、底部警戒胶带、Z字阅读路径
4. 背景设计：纯色+轻微纹理，简洁现代
5. 人物风格：按用户选择动态生成
6. 左侧人物A：五官参考角色图1，动作固定双腿交叉坐地
7. 右侧人物B：五官参考角色图2，动作固定双腿盘坐
8. 灯光：顶部主光 + 左上补光 + 底部环境反光
9. UI设计：Console Game Menu风格，统一圆角矩形按钮
10. UI排版：横向长条按钮，标题单行禁止换行
11. 按钮设计：Continue超大高亮居中
12. 玩家信息卡：左上角不规则矩形卡片
13. 图标系统：单排横向，禁止换行堆叠
14. 字体设计：超粗无衬线，全部大写

### 关键原则
- 首图确认前不生成视频
- 上传角色图只用于身份映射（脸型、发型、五官比例），不继承真人质感
- 人脸必须在保留身份锚点前提下重绘为用户选择的视觉风格

### 不适用
完整游戏开发、复杂多页面UI

---

## 7. 纸拼贴讲解动画生成器

### 定位
用触感纸拼贴语言表现口播句、知识点、观点或抽象主题。高级半调纸拼贴风格。

### 核心流程
```
解析输入 → Gate 1:制作方案确认 → 静帧规格 → Gate 2:生成确认静帧 → 规划停格组装 → 生成B-roll片段 → 质量检查 → 可选合成
```

### 视觉风格签名
```
flat bold color field, black-and-white halftone photographic cut-outs, selective colored cardstock accents, warm cream keylines, soft paper shadows, fine uncoated-paper grain, premium editorial paper collage, clean refined hand-torn paper edges, subtle fibrous edges, layered paper seams
```

### 默认音频策略
- 默认保留/生成触感拼贴音效：纸片滑动、弹入、压平轻敲、摩擦、脆响
- 默认不添加BGM，除非用户明确要求
- 默认不添加旁白口播，除非用户明确要求
- 默认不添加字幕，除非用户明确要求

### 停格组装运动顺序
1. 从与静帧主背景一致的干净纸色场开始
2. 基础结构滑入/弹入/压入
3. 角色和主要隐喻元素入场
4. 次要物件逐个组装，带回弹、压平、暂停
5. 锁定到已批准构图
6. 短暂停留在完整画面

### 色彩语义
- 焦橙/红色：劳动、紧迫
- 芥末黄：工具、警示
- 墨绿：认知、重置
- 深紫：记忆、神秘
- 青绿：协作、系统流动
- 玫红：荒诞、戏剧张力

### 质量检查要点
- 视觉隐喻无需文字也能理解
- 组装是逐片可见的，不是整体淡入
- 运动像定格拼贴：弹入→回弹→压平→暂停→锁定
- 纸张质感可控：不太平、不太旧、不偏棕

### 不适用
真人口播广告、精确文字排版

## 8. 手绘实拍视频生成器

### 定位
制作15秒16:9手绘实拍融合短片。平面手绘发光动画出现在真实空间中，与实拍手/物体接触，连续变形逃跑。

### 固定结构
- 0-3秒：实拍手与手绘动画的清晰接触
- 3-6秒：连续变形和移动
- 6-10秒：新的变形、接触、发现
- 10-13秒：恶作剧或惊喜
- 13-15秒：空间级变形 + 感动余韵 + 可爱笑点

### Prompt 11段固定顺序
1. 开头句（`15秒，16:9横版视频。将实拍的〇〇与手绘发光动画融合的影像。`）
2. 实拍空间与手机拍摄质感
3-7. 五个时间段描述
8. 手绘质感（蜡笔/粉笔/彩色铅笔/粉彩/粗糙笔刷）
9. 相机追随方式（慢半拍手持追拍）
10. 禁止事项（3DCG/毛绒感/恐怖/跳吓）
11. 环境音

### 核心规则
- 动画作为同一个实体连续变形，保留前一形态的痕迹
- 不允许突然出现另一个全新角色
- 全片在同一空间连续展开，不剪辑跳到另一地点
- 相机慢半拍：实体离开画面边缘后才平移/俯仰/前进
- 调性：可爱、生活感、怀旧、温柔，不是恐怖

### 每次重新发明创意
不复用参考prompt中的暗房、电脑、冰箱、星星、爱心、蓝色漩涡、蝴蝶、蛇、章鱼、汉堡等元素。每次选择新的实拍空间、手绘实体、色彩、变形链路、接触方式、追逐路线。

### 不适用
精致CG、恐怖跳吓、多场景剪辑

## 风格选择速查表

| 需求关键词 | 推荐风格 |
|------------|----------|
| 产品/电商/Apple风/新品 | 极简产品广告 |
| 3D/动画/皮克斯/剧情 | 3D动画短片 |
| 纸艺/科普/教育/知识 | 纸艺定格科普 |
| 品牌/宣传/新品发布/社媒 | 品牌宣传短片 |
| MV/音乐/歌词/情绪 | 音乐美学MV |
| 游戏/双人/菜单/开场 | 双人游戏开场 |
| 拼贴/讲解/观点/B-roll | 纸拼贴讲解 |
| 手绘/实拍/创意/融合 | 手绘实拍融合 |
| 模特/服装/时尚/展示 | 通用 Ref2VA（非风格专项） |
| 直播/带货/教程 | 通用 Ref2VA（非风格专项） |
| 循环/无缝/表情 | 通用 Ref2VA（非风格专项） |

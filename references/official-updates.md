# 官方使用手册更新提炼（2026-09 版）

> 来源：MiniMax 官方飞书文档《🐚MiniMax H3 模型 - 使用手册》（2026-09-01 更新）。
> 本文件只收录现有 Skill 未覆盖或与官方口径有差异的增量内容，与主流程配合使用。

## 1. 完整基础规格（补全）

| 参数 | 官方口径 |
|------|----------|
| 输出时长 | 4–15 秒 |
| 输出宽高比 | 首/尾帧模式：遵循输入图片原始长宽比；文生视频：用户指定 21:9、16:9、4:3、1:1、3:4、9:16；全能参考：同上 6 种或"自动模式"由 H3 自行判断 |
| 分辨率 | 768p：宽高比在 16:9～9:16 之间时短边 768px，否则总面积约 1M px（如 21:9 → 1536×672），768p 结果可升级至 1440p；1440p（官方推荐）：16:9～9:16 之间短边 1440px，否则约 3.7M px（如 21:9 → 2976×1248） |
| 帧率 / 声音 | 24 FPS，全部结果带声音，原生双声道 |
| 提示词上限 | 不超过 7000 字符 |

### 输入素材硬限制

| 入口 | 限制 |
|------|------|
| 首/尾帧 | 图片 0、1、2 张；宽高范围 [256, 5760]；宽高比 5:2～2:5 |
| 全能参考 | 图片 ≤9 张；视频 ≤3 段（单段 2–15 秒、总时长 ≤15 秒）；音频 ≤3 段（必须搭配图片或视频，不能单独输入，单段 2–15 秒）；混合输入总上限 12 个文件 |
| 格式 | 视频 H.264/H.265（内音频 AAC/MP3）；图片 JPG/JPEG/PNG/WEBP/HEIC/HEIF；音频 WAV/MP3 |
| 大小 | 视频单个 50MB、图片单个 30MB、音频单个 15MB（限单素材，总量不限）；API 请求体 64MB（推荐 url 传素材） |
| 语言 | 多语言提示词输入输出；TTS 精准 11 种（中/英/日/韩/法/德/西等），可衍生 40+ 种（阿拉伯语、泰语、印尼语、印地语等） |

## 2. 官方提示词公式（三段式）

```
完整提示词 = 参考素材说明 + 核心创意 + 画面过程说明
```

### 2.1 参考素材说明

- 按上传顺序写清编号：`@图片1`、`@音频2`、`@视频3`。
- 每个素材写明用途，官方支持 14 类：人物参考（锁脸/形象）、物体参考、场景参考、关键帧（首帧/尾帧需明确）、音色参考、故事版（按分镜生成镜头）、风格参考、构图参考、音频复用、音频部分复用（某个声道/时间段）、动作参考、运镜参考、视频编辑（对内容增删改）、其他要求。
- 无素材时整段跳过。
- 音频复刻时若要求保持人声对白/歌词，强烈建议附上具体歌词文本。

### 2.2 核心创意（一句话锁定全片）

必含五要素：主体 + 地点 + 事件 + 题材/风格 + 特殊运镜。

- 默认会切镜；切镜风格可指定：普通切镜（cut）、叠化（fade）、卡点切镜、快切。
- 环绕运镜不要直接写"环绕"，建议写 `truck left + pan right` 或 `truck right + pan left`。
- 与素材有关联的元素用 `@图片1` 等方式强调。

### 2.3 画面过程说明（按时间轴/shot 分段）

每段包含"想要 + 不想要"两部分：

- **想要**：景别 + 内容 + shot 内运镜 + 动作 + 台词 + 音效；文字/Logo/标题/按钮文案必须写出原文（例：画面中出现英文 "H3"；手机屏幕显示标题 "AI Video Creation"、按钮 "Start Now"）。
- **不想要**：不要 BGM 时在提示词最后明确写 `非叙事性音乐：N/A`（或英文 `"non_diegetic_music": N/A`）；少写比喻句，多写看得见的画面；台词必须写具体内容。
- 有非常想保持的特征要明确写出，一致性更好。

## 3. 镜头拆解规则（官方口径）

- 台词长短必须与 shot 时长逻辑对齐，3 秒 shot 塞一大段话会明显伤效果（口型问题的主要来源之一）。
- 支持跨 shot 台词（J-cut / L-cut）：明确写出"这句台词跨了哪些 shot"或"接着上个 shot 继续说"。
- 说话人归属：画面内说话写清是哪个角色；画外音写明"画外"；因切镜发生画内外转换的，明确写出（例：画外音响起 "Wake up"，切镜到中年妇女近景，她是画外音主人，继续说 "It's time to go to school!"）。
- 切镜一致性：切镜时明确写出切到什么景别、主体是之前的哪个角色。

## 4. 三类模式写法要点

| 模式 | 要点 |
|------|------|
| 多模态参考 | 每个素材写清角色分工（如 @图片1 锁脸、@视频1 锁动作、@音频1 情绪/节奏参考） |
| 图生视频 | 只传 1 张图时说清是首帧还是尾帧；传 2 张图（首+尾帧）时 H3 不会自动加切镜，只补两帧之间的动作、光影、声音 |
| 纯文字 | 描述要更具体（主体外观+场景细节+动作+风格）；用"大全景交代空间 + 中景承载动作 + 特写强调细节"分层写法 |

## 5. 视频编辑模式（全新能力域）

对已有视频做增删改，四类操作：

- **角色与物体编辑**：替换（把视频中的猫换成狗）、增加（画面左边增加一个穿相同制服的人，动作与旁人一致）、删除、细节精准替换（最后面的小孩换成图1的金毛狗；卡其色外套改成图2的牛仔外套）。
- **场景与视觉编辑**：绿幕抠像换背景（背景元素完全匹配人物动作 + 修改人物光线匹配新背景）、光照替换（改成夜晚）、窗外景色替换。
- **声音、台词与音色修改**：台词替换（原句 → 新句，可附带音频1作为新台词音色参考，并要求"略微调整对应的表演"）。
- **高精度指令遵循**：单条提示词并行多条修改指令（报纸→绿皮书；椅子→红色沙发；去掉墨镜；移除燃烧效果；照片→黑色小本子；左侧加一棵树），未提及内容保持不变。

编辑提示词要点：以原视频为基础时，明确列出"必须 100% 保持不变"的清单（镜头运动、运动时序、透视、光影方向、遮挡关系、整体氛围），替换元素需与原画面无缝融合。

## 6. 出海多语种对白写法

- 多语种台词直接写母语原文（可附中文注释），并标注口音（如"沙特阿拉伯口音""Napoli 口音""东京 20 代女生日常口语"）。
- 分段写对白：时间段 + 景别 + 角色动作/表情 + 台词原文 + 语气说明，并标注"口型精确同步"。
- 不说话的角色明确"保持安静，不做说话口型"。
- 适合海外品牌传播、多语种广告、跨语言短片、本地化产品介绍。

## 7. 商用场景十类（场景选型清单）

1. **品牌大片与影视**：电影预告、TVC、品牌质感大片（关键帧连续+道具转场、预告片式标题包装）。
2. **视觉创意与内容包装**：创意短片、特效包装、MV、社媒素材（复古动画拼贴片头、实拍+手绘融合、动态海报）。
3. **动态图形/MG 动画/AE 特效**：品牌 MG 短片、平面动态图形、中文动态字体实验、TouchDesigner 式追踪图形。
4. **AR 现实增强**：在原视频上做 AR 实景合成与世界编辑（严格沿用原视频真实镜头/手部动作/透视）。
5. **AI 剧情内容**：竖屏短剧、漫剧、角色演绎（古装武侠、家庭争吵、海外吸血鬼爱情短剧预告）。
6. **产品与电商营销**：产品展示、卖点视频、投流素材（白棚时尚广告、产品功能工程动画、美食发布视频）。
7. **数字体验与游戏创意**：游戏 UI、网页 UI、产品界面交互演示（分时段写 UI 动效与光标行为）。
8. **硬件/实体工业/具身智能**：机器臂演示、精准背景替换。
9. **动画与风格化影像**：游戏 CG、角色 PV、动漫 PV、二次元（黏土动画、国风仙侠 3D、乙游 PV、FPS 第一人称）。
10. **出海多语种**：见第 6 节。

## 8. 官方新增 Tips 与易踩坑

**文字乱码官方解法**：处理文字遇乱码时，把文字做成图片提供给 H3 作参考图，并在提示词明确"这张内容必须按'图片'来理解，不能按'文字'来处理"，通常能有效降低乱码。

| 常见问题 | 怎么改 |
|----------|--------|
| 只写一段话没分段 | 按"参考素材说明 + 核心创意 + 画面过程说明"三段公式拆开 |
| 素材上传了但没说用途 | 补一句"@图片1 是 XX 参考" |
| 想用音乐但说"不要 BGM" | 两者矛盾，删一个或分场景写 |
| 想一镜到底但写了很多分镜 | 全文保持一段情节描述，删掉【镜头 N】结构 |
| 想要主角脸一致但没传图 | 必须上传人物参考图并标注"人物参考" |
| 提示词太短（无素材时） | 至少写出主体外观 + 场景细节 + 动作 + 风格 |

## 9. 风格示例补充写法

官方完整示例（大字幕 MV、手绘特效）展示了两个可复用结构：

- **大字幕 MV**：参考素材说明（按维度声明只参考指定维度、不复制 logo）→ 核心创意 → 逐 Shot 描述（场景/景别/人物/文字/律动五项）→ 整体要求补充（影像风格/文字包装/律动规则/场景切换/景别切换/人物规则/重要限制分组书写）。
- **手绘特效**：每时间段用"正向（要什么）/反向（不要什么）"成对书写；变形链要求"每次变形保留前一形态痕迹"，保证连续感；相机"慢半拍追随"制造真实感。
